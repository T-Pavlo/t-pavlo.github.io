Privacy Policy

Last updated: November 23, 2026

Hindsight Corp. ("we") runs the YouTube channel @HindsightCorp and an internal tool, "Hindsight uploader", that uploads our own videos to our own YouTube channel.

YouTube API Services

Hindsight uploader uses YouTube API Services. By using it, you agree to be bound by the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy.

What the app accesses

The app uses the YouTube Data API only to upload videos, set thumbnails and add videos to playlists on the Hindsight Corp. channel, and to confirm which channel is authorized. It is used only by the channel owner.

What data we collect, use and share

We do not collect, store, sell or share personal data of any users or viewers. The only data the app keeps is the channel owner's own OAuth refresh token, stored as an encrypted secret and used only to access the owner's own channel. The video ID returned after an upload is used immediately to set the thumbnail and playlist, and is not stored elsewhere. We do not use cookies or tracking on this website.

Data retention and deletion

We keep no API data beyond the owner's OAuth token. To delete it, the owner revokes access at Google security settings (myaccount.google.com/permissions) and the stored token is deleted from our environment within 7 days. Any authorized data obtained from YouTube API Services is deleted or refreshed at least every 30 days, as required by the YouTube API Services Developer Policies. To request deletion, contact us through our YouTube channel.

Google API Services User Data Policy

The app's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
